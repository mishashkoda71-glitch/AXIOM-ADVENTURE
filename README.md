# AXIOM ADVENTURE

Новая версия приключенческой игры на **C# + Stride 4.4.1** с целью сборки под Android.

## Текущий статус
- [x] Репозиторий и облачный workflow на GitHub Actions.
- [x] Общая игровая логика на C#.
- [x] Здоровье, урон, лечение, монеты и кристаллы.
- [x] Враги-слизни и награды за победу.
- [x] Прогресс кампании на 40 уровней.
- [x] JSON-сохранение и восстановление.
- [x] Автоматические проверки игровой логики.
- [ ] Успешная сборка Android APK в GitHub Actions.
- [ ] Игровая сцена Stride, управление и визуальные эффекты.
- [ ] Звуки, меню, уровни и тестирование на Android.

## Проект
- `AxiomNext/src/AxiomNext.Core` — независимая от движка игровая логика.
- `AxiomNext/src/AxiomNext.Core.Tests` — быстрые проверки логики.
- `AxiomNext/README.md` — подробности новой версии.
- `.github/workflows/axiom-next-ci.yml` — облачная сборка Android APK.

Сборка запускается автоматически при изменениях в `AxiomNext/` или вручную из вкладки **Actions**.

## Работа с телефона
Все исходники и сборка находятся в GitHub. Локально устанавливать компилятор или создавать ZIP на Android не требуется.

Старые Unity-файлы пока сохранены в репозитории как резерв. Новая версия собирается отдельным Stride workflow.
