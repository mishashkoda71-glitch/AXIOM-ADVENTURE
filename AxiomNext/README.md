# AXIOM ADVENTURE — новая C#-основа

Новая разработка ведётся в каталоге `AxiomNext/`. Существующие Unity-файлы пока сохранены без изменений: это резервная копия прежней версии, а не требование устанавливать Unity.

## Цель
Подготовить исходный C#-проект, который можно развивать через GitHub с телефона, а компилировать в облаке через GitHub Actions.

## Принятые ограничения
- Разработка и управление файлами — только GitHub.
- Локальный компьютер и локальный игровой редактор не требуются.
- Основной язык — C#.
- Целевая платформа — Android.
- Игра: AXIOM ADVENTURE / Slumpy Slimes.
- Планируемая кампания: 40 уровней (параметр будет уточнён по мере восстановления прежнего дизайна).

## Текущий этап
Создан независимый от движка слой игровой логики (.NET 8). Это позволяет проверять правила игры в облаке, прежде чем добавлять Android-рендерер и сетевые/графические зависимости.

## Структура
```
AxiomNext/
  README.md
  src/
    AxiomNext.Core/
      AxiomNext.Core.csproj
      GameSession.cs
      LevelProgress.cs
```

## Важное
Это пока фундамент игровой логики, а не готовая 3D-игра и не APK. Следующий технический выбор — графический движок/рендерер с подтверждённой Android-сборкой из GitHub Actions. Существующие файлы в корне не удаляются, пока новая сборка не будет проверена.
