# AXIOM ADVENTURE — Stride + C#

Новая версия игры создаётся на **Stride 4.4.1** — C#-движке с поддержкой Android. Unity и Godot не используются для новой версии.

## Работа без компьютера
- Исходники хранятся в этом GitHub-репозитории.
- Проект Stride создаётся из официального .NET-шаблона прямо в GitHub Actions.
- Android APK собирается в облаке.
- Редактор Stride Game Studio сейчас доступен только на Windows, поэтому этот рабочий процесс не требует от тебя устанавливать редактор на телефон.

## Технологии
- Язык: C#
- Движок: Stride 4.4.1
- Целевая платформа: Android
- .NET: 10
- Ориентация: альбомная (Landscape)

## Исходники
`src/AxiomNext.Core/` содержит независимую от движка игровую логику:
- `GameSession.cs` — сессия, состояние игрока, здоровье и кристаллы.
- `LevelProgress.cs` — открытие и завершение уровней.

При облачной сборке библиотека подключается к сгенерированному Stride Game-проекту.

## Сборка APK
Открой вкладку **Actions** в GitHub и запусти workflow **AXIOM NEXT - Stride Android** через **Run workflow**. После успешной сборки APK будет доступен в разделе Artifacts этого запуска.

## Важно
Переход выполняется безопасно: старые Unity-папки в корне пока не удаляются. Они не участвуют в новом Stride workflow. Удалять их будем только после того, как Stride APK успешно соберётся и проверится.
