# AXIOM ADVENTURE — Stride + C#

Новая версия игры создаётся на **Stride 4.4.3** — C#-движке с поддержкой Android. Новая версия не использует Unity, Godot, HTML5 или JavaScript.

## Работа без компьютера
- Исходники хранятся в GitHub.
- Проект Stride создаётся из официального .NET-шаблона в GitHub Actions.
- Проверки игровой логики и Android APK выполняются в облаке.
- Редактор Stride Game Studio пока не нужен для запуска этого процесса.

## Технологии
- Язык: C#
- Движок: Stride 4.4.3
- Платформа: Android
- .NET: 10
- Ориентация: Landscape

## Что уже реализовано в общей игровой логике
- Игровая сессия и профиль игрока.
- Здоровье, получение урона и лечение.
- Монеты и сбор уникальных кристаллов.
- Слизни-враги, получение урона и награда за победу.
- Кампания на 40 уровней с последовательным открытием.
- Версионированное JSON-сохранение и восстановление прогресса.
- Автоматические проверки этих правил без сторонних тестовых библиотек.

## Структура
- `src/AxiomNext.Core/` — игровая логика, независимая от движка.
- `src/AxiomNext.Core.Tests/` — исполняемые проверки логики.
- `.github/workflows/axiom-next-ci.yml` — облачная сборка Android APK.

## Сборка APK
Открой вкладку **Actions** и запусти **AXIOM NEXT - Stride Android** через **Run workflow**. После успешного выполнения APK появится в разделе Artifacts соответствующего запуска.

## Статус
Игровая логика и тесты находятся в репозитории. Android-проект Stride генерируется в CI из официального шаблона. Сейчас проверяется сборка ресурсов Stride на Linux runner. До успешной сборки и проверки APK старые Unity-файлы сохраняются как резерв.
